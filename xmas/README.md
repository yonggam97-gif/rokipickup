# 🎄 미리메리 크리스마스 — 산타요정 지도

서전로 귀신의집 앱을 크리스마스용으로 바꾼 앱이에요.

| 화면 | 주소 | 누가 써요 |
|---|---|---|
| 손님 지도 | `index.html` | 손님 (QR로 들어옴) |
| NPC 위치 보내기 | `npc.html` | 산타요정 배우 |
| 관제실 | `control.html` | 운영팀 (PC 추천) |

## 지금 되는 것
- 🎅 **산타요정 실시간 위치**: NPC가 `npc.html`을 켜 두면 손님 지도·관제실에 떠요. 3분 넘게 소식이 없으면 회색 "n분 전 위치", 10분 넘으면 사라져요.
- 📬 **산타 메시지**: 관제실에서 보내면, 앱을 켜 둔 손님에게 "산타로부터 메시지가 도착했어요!" 팝업이 뜨고 **인스타에서 확인하기** 버튼이 나와요. 앱을 1시간 안에 연 손님도 받아요.
- 📊 **통계**: 메시지마다 팝업을 본 사람 수, 인스타 버튼을 누른 사람 수 (폰 1대 = 1명).
- 🙈 **숨기기**: 관제실에서 산타별로 손님 지도에 보이기/숨기기.
- 🎁 **제휴 매장**: 귀신의집 매장 26곳 그대로. 지도에서는 크리스마스 장식 방울로 보여요.

## 연습 모드
`js/config.js`의 Firebase 칸이 비어 있으면 **연습 모드**예요.
- 손님 지도에 가짜 산타가 돌아다니고, 7초 뒤 예시 메시지가 떠요.
- 같은 폰/PC 브라우저 안에서는 `npc.html` → `index.html` → `control.html`이 서로 연결돼요. (비밀번호 아무거나)
- 실제 서버가 연결된 뒤에도 주소 끝에 `?demo` 를 붙이면 연습 모드로 볼 수 있어요.

## 실제 서버 연결 (Firebase, 약 10분)
1. https://console.firebase.google.com → **프로젝트 추가** (이름 예: mirimerry, 애널리틱스는 꺼도 돼요)
2. 왼쪽 **빌드 → Realtime Database → 데이터베이스 만들기** → 위치: **싱가포르(asia-southeast1)** → **잠금 모드로 시작**
3. Realtime Database의 **규칙** 탭 → 이 폴더의 `database.rules.json` 내용을 통째로 붙여넣고 **게시**
4. **빌드 → Authentication → 시작하기 → 이메일/비밀번호** 사용 설정
   → **사용자 추가**: 이메일 `staff@mirimerry.app`, 비밀번호는 원하는 걸로 (스태프끼리만 공유)
5. **프로젝트 설정(톱니바퀴) → 내 앱 → 웹(`</>`)** → 앱 등록 → 나오는 `firebaseConfig` 값을 `js/config.js`의 `FIREBASE_CONFIG`에 붙여넣기
   (`databaseURL`이 없으면 Realtime Database 화면 맨 위 주소를 넣어주세요)
6. **요금제**: 무료(Spark)는 **동시 접속 100명**까지예요. 행사 때 손님이 더 많으면 **Blaze(종량제)** 로 바꾸고 **예산 알림**(예: 1만 원)을 걸어두세요. 이 규모면 거의 0원이에요.

> Firebase 설정값은 비밀번호가 아니에요. 코드에 넣어도 괜찮고, 보안은 3번 규칙 + 4번 로그인으로 지켜요.

## NPC 위치 보내는 방법
### 1단계 (지금 바로): `npc.html` 웹 화면
- 로그인 → 내 산타 고르기 → **출동!** 버튼
- **화면이 꺼지면 위치가 멈춰요.** 화면 켜짐 유지 기능을 켜 두지만, 폰 자동잠금도 꺼두는 게 안전해요. 보조배터리 필수.

### 2단계 (화면 꺼져도 되게): 안드로이드 공기계 + Traccar Client 앱
조사 결과 가장 현실적인 방법이에요. (전용 GPS 트래커는 우리 앱으로 위치를 빼오는 기능이 없거나, 해외 직구 전파인증 문제가 있어서 비추천)
1. Firebase를 **Blaze** 요금제로 바꾸기 (함수 기능에 필요)
2. `functions/` 폴더를 배포: `firebase deploy --only functions` (배포 때 `TRACCAR_KEY` 비밀번호를 정해요)
3. NPC 폰에 **Traccar Client** 설치 → 설정
   - 기기 ID: `santa1` 처럼 `js/santas.js`의 id
   - 서버 주소: 배포된 함수 주소 + `?key=정한비밀번호`
   - 정확도: 높음, 간격: 10~15초
   - 폰 설정: 위치 권한 "항상 허용", 배터리 절전 예외
4. 행사 전에 1대로 30분 걸어보며 확인 (화면 끈 상태에서도 오는지, 배터리 얼마나 쓰는지)

## 알림에 대해
- 지금 알림은 **앱을 켜 둔 동안** 팝업으로 와요 (소리·진동 포함).
- 앱을 꺼도 오는 진짜 푸시 알림은 Blaze + 추가 개발이 필요하고, 아이폰은 "홈 화면에 추가"한 손님만 받을 수 있어요.
- 인스타에 올리면 자동으로 알림이 가는 기능은 메타(인스타) 앱 승인이 필요해서, 지금은 **관제실에서 링크를 붙여넣고 보내는 방식**이에요.
